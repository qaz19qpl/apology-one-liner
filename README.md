# The AI Agent Apology One-Liner

A make.fun entry for [The AI Agent Apology One-Liner](https://make.fun/competitions/u-kiencx-the-ai-agent-apology-one-liner-cfedd447): one funny line an AI agent sends its human right after it accidentally deleted a file, pushed to main, or emailed the boss.

`main.ts` (Node 22, stdlib only) writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
